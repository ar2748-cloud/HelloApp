# HelloApp

HelloApp is a Java console application that demonstrates the gradual development of programming concepts.

## Features
- Display Hello World
- Accept user name
- Read command line arguments
- Read standard input
- Manage names using collections
- List and remove names
- Refactor code using methods and classes
- Persist names across runs
- Display names in banner format

## Project Structure

src/  - Java source code  
bin/  - Compiled class files  
docs/ - Documentation and use cases  

## Run the Application

Compile:
javac src/HelloApp.java -d bin

Run:
java -cp bin HelloApp
